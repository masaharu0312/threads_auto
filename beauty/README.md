# Threads 自動投稿（ブラックじゃない美容のお仕事案内）

どこでもMUSEE の自動投稿と同じ仕組みで、別アカウントに文章だけの投稿を1日3回出します。
1投稿は「本文（つかみ）＋自分のコメント3つ」のスレッドで、メインの中身はコメントに書きます。
本文には、つかみに合うイラスト（OpenAI の画像生成）を付けます。
検索・行動の投稿は、最後に紹介文とアフィリエイトリンクのコメントを付けます。

| 枠 | 時刻 | 種類 |
|---|---|---|
| 朝 | 7:30 | 認知 |
| 昼 | 12:30 | 興味関心 |
| 夜 | 21:00 | 検索・行動を交互に（日曜だけ認知） |

見送りになった投稿などを空き時間に出し直すときは、「枠」を `午前`（10:00）か `夕方`（18:00）にして日付を入れ直し、「状態」を消します（下書き作成では使わない枠です）。

1週間で 認知8・興味関心7・検索3・行動3（教材の 7：3）になります。

GitHub の定時実行は大きく遅れたり飛ばされたりするので、MUSEE と同じ Google Apps Script（`apps_script/trigger.gs`）が
10分ごとに美容用シートも見て、予定時刻を過ぎた承認済みの投稿があれば「美容 Threads 投稿」を呼び出します（予定の0〜10分後に出ます）。
Apps Script のスクリプト プロパティに `BEAUTY_SHEET_ID` が無いときは、美容のほうは定時実行だけで動きます。

## 毎週の流れ
1. **日曜 10:30**：Claude が翌週7日分（21投稿）の本文・コメント・紹介文を作り、美容用スプレッドシートの「投稿」に追加します。
   続けて、本文ごとのイラストを OpenAI で作り、`beauty/images/` に置いて「画像URL」列に書きます。
2. **あなた**：本文・コメント・紹介文・画像を確認し「承認」にチェック。文言は直接直してOKです。
3. **毎日**：承認済みの投稿だけが出ます。本文のあと約30秒おきに、「コメント」列の中身を1つずつ返信としてつなげます。検索・行動の投稿は、最後に紹介文（`#PR` ＋紹介文＋リンク）が付きます。
4. 結果（状態・投稿URL・コメントURL・エラー）はシートに書き戻されます。

- 画像が気に入らないときは、Actions →「美容 イラストを作成」→ `redo` に投稿のID（例 `2026-11-03-朝`）を入れて作り直します。
  「画像URL」を空にすると、その投稿は文章だけで出ます。
- 「コメント」列は、`---` だけの行で区切ると別々のコメントになります。
- 紹介文の「○○」は、投稿時に設定シートのサービス名に置き換わります。
- サービス名かリンクが未入力の紹介先を使う投稿は、本文も出さずに「エラー」になります（「次のコメントに」が空振りしないように）。
- 途中のコメントで失敗した場合は「コメント失敗」になり、3時間以内なら見回りのたびに続きのコメントから付け直します。3時間を過ぎると「投稿済み（コメント途中）」です。

## 初期設定（最初に1回）
MUSEE 用と共通のもの（`GOOGLE_SERVICE_ACCOUNT_JSON`・`ANTHROPIC_API_KEY`・`THREADS_APP_SECRET`、Meta アプリ）はそのまま使います。

1. **Threads アカウント**：美容用のアカウントを作り、プロフィールを設定します（案は `threads_beauty_job/account_design.md`）。
2. **Meta アプリ（threads-auto）**
   - 権限に `threads_manage_replies` を追加します（コメント欄への返信に必要）。
   - 「役割」で美容用アカウントをテスターに追加し、Threads アプリ側で招待を承認します。
   - ユーザートークン生成ツールで、美容用アカウントのトークンを発行します。
3. **スプレッドシート**：空のスプレッドシートを作り、`threads-bot@threads-auto-512712.iam.gserviceaccount.com` に「編集者」で共有します。
4. **GitHub Secrets** に追加
   | 名前 | 中身 |
   |---|---|
   | `BEAUTY_SHEET_ID` | 美容用スプレッドシートのID |
   | `BEAUTY_THREADS_TOKEN` | 美容用アカウントのトークン |
   | `OPENAI_API_KEY` | イラスト用の OpenAI API キー（無ければ文章だけで投稿） |
5. Actions →「美容 初期設定（シート作成・トークン登録）」→ Run workflow。
6. 「設定」シートに、ASP で決めた案件のサービス名・リンク、案件の禁止表現を入力します。
7. 最初の1週間分を取り込む：Actions →「美容 翌週の下書きを作成」→ `from_json` に `beauty/drafts/2026-11-03_week.json`。
   日付を変えたいときは、シートの「日付」列を直します（IDは変えなくてOK）。
   取り込み済みの行をJSONの内容で入れ直すときは `replace` にチェックします（まだ投稿していない行だけ上書きされ、承認は外れます）。

`BEAUTY_SHEET_ID` が未登録のあいだは、投稿・下書き作成のワークフローは何もせずに終わります。

## ルール
- 投稿内容のルール（架空の体験談を作らない、統計や断定を書かない など）は `knowledge.md` にあります。
- `voice_examples.json` は語り口の見本です。いまは Claude が作った下書きなので、気に入った投稿ができたら差し替えてください。
